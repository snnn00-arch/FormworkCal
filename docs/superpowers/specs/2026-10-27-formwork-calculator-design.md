# เอกสารออกแบบระบบ (System Design Specification)
## เว็บแอปพลิเคชันคำนวณและจัดเรียงไม้แบบสำเร็จรูป (Modular Beam Formwork Calculator Web App)

**วันที่:** 2026-10-27  
**สถาปัตยกรรม:** Pure Client-Side Interactive CAD Web App (React + TypeScript + Vite + TailwindCSS + PDF.js + HTML5 Canvas)  
**ดีไซน์ธีม:** Minimal White Engineering CAD (`#FFFFFF`, `#F8FAFC`, เส้นขอบบาง `#E2E8F0`, ตัวอักษรคมชัด `#0F172A`)

---

## 1. วัตถุประสงค์และขอบเขตของระบบ (Purpose & Scope)

เว็บแอปพลิเคชันสำหรับวิศวกรและผู้รับเหมาก่อสร้างในการนำเข้าไฟล์ **PDF แปลนคาน** ตั้งค่าสเกล (Auto หรือ Manual) แล้วให้ระบบช่วยตรวจจับแนวคานหรือลากแนวคานเพื่อ **คำนวณและจัดเรียงไม้แบบสำเร็จรูปสำหรับเช่า (ข้างคาน 2 ฝั่ง)** ลงบนแปลนโดยอัตโนมัติ พร้อมคำนวณความหนาไม้แบบ ระยะอมมุม/ชนมุม และแยกส่วนที่เหลือเป็น **"ระยะความยาวฟรี (ไม้ตัดเสริมหน้างาน)"** โดยสามารถปรับแก้ (Edit) เพิ่มเติมได้ และสรุปยอดจำนวนไม้แบบแยกตาม **ความยาว × ความสูง** พร้อมส่งออกแปลนการวางแบบแยกสี (PDF/PNG) และตารางสั่งเช่าของ (CSV/Excel)

## 2. ข้อมูลมาตรฐานไม้แบบสำเร็จรูป (Formwork Catalog Matrix)

ระบบรองรับไม้แบบสำเร็จรูปสำหรับเช่า แบ่งตาม **ความยาว 3 ขนาด** และ **ความสูง 4 ขนาด** รวมทั้งสิ้น **12 รายการมาตรฐาน (SKUs)** และรายการ **ความยาวฟรี (Free-Length Filler)** แยกตามความสูง 4 ขนาด:

| ประเภท | ความยาว (Length) | ความสูงที่รองรับ (Height - 4 ขนาด) | สีสัญลักษณ์บนแปลน (Color Coding) | รหัสตัวอย่าง (SKU Code) |
| :--- | :--- | :--- | :--- | :--- |
| **แบบเช่ามาตรฐาน 120** | `120 ซม.` | `40`, `50`, `60`, `70 ซม.` | 🟢 สีเขียว (`#10B981` Emerald) | `FW-120x40`, `FW-120x50`, `FW-120x60`, `FW-120x70` |
| **แบบเช่ามาตรฐาน 100** | `100 ซม.` | `40`, `50`, `60`, `70 ซม.` | 🔵 สีน้ำเงิน (`#3B82F6` Royal Blue) | `FW-100x40`, `FW-100x50`, `FW-100x60`, `FW-100x70` |
| **แบบเช่ามาตรฐาน 50** | `50 ซม.` | `40`, `50`, `60`, `70 ซม.` | 🟠 สีส้ม (`#F59E0B` Amber) | `FW-50x40`, `FW-50x50`, `FW-50x60`, `FW-50x70` |
| **ระยะความยาวฟรี (ไม้ตัดเสริม)** | `> 0 ซม.` (ตามเศษจริง) | `40`, `50`, `60`, `70 ซม.` | 🔴 สีแดงเส้นประ (`#F43F5E` Dashed Rose) | `FREE-[L]x40`, `FREE-[L]x50`, `FREE-[L]x60`, `FREE-[L]x70` |

> **การแสดงผลความสูงบนแปลน:** นอกจากสีที่แยกตามความยาว (`120`, `100`, `50`, `Free`) แล้ว บนแผ่นไม้แบบในแปลนจะแสดงป้ายกำกับ `ความยาว×ความสูง` (เช่น `120×60`, `100×50`, `F35×60`) และสามารถกรอง (Filter/Highlight) ดูเฉพาะความสูงที่ต้องการ (`40`, `50`, `60`, `70 ซม.`) บนแปลนได้

## 3. สถาปัตยกรรมและโครงสร้างโมดูล (System Architecture & Modules)

ระบบแบ่งออกเป็น 5 โมดูลหลักที่แยกหน้าที่กันอย่างชัดเจน (Modular Isolation):

1. **`pdfEngine` (PDF Renderer & Vector/Text Extractor):**
   * ใช้ `pdfjs-dist` โหลดไฟล์ PDF แปลนคาน แปลงเป็น Canvas พื้นหลังความละเอียดสูง
   * ดึงข้อมูล Vector Paths (เส้นตรงในแปลน CAD) และ Text Content (ตัวเลขบอกระยะ เช่น `4.00`, `4000`, ชื่อคาน `B1`, `GB1`) ออกมาในรูปแบบพิกัดระนาบเดียวกันกับ Canvas
2. **`scaleCalibrator` (Auto & Manual Scale Manager):**
   * **Auto Scale:** วิเคราะห์หาคู่ข้อความตัวเลขบอกระยะและเส้น Dimension ใน PDF เพื่อคำนวณค่า `pixelsPerCm` อัตโนมัติ (หรือตั้งต้นตามสเกลมาตรฐาน 1:100, 1:50, 1:75 จากหน้ากระดาษ A3/A1)
   * **Manual Scale:** เครื่องมือคลิก 2 จุดบนแปลน (`Point A -> Point B`) แล้วกรอกระยะจริง (ซม. หรือ ม.) เพื่อคำนวณค่า `pixelsPerCm` ที่แม่นยำ 100%
3. **`beamDetector` (Auto Beam Detection & Manual Beam Editor):**
   * **Auto-Detect:** ค้นหาคู่เส้นขนานจาก Vector PDF ที่มีระยะห่างกันในช่วงความกว้างคาน (เช่น `15 - 40 ซม.`) และสร้างเป็นรายการคาน (`BeamSegment`) เบื้องต้น
   * **Manual Draw & Edit:** เครื่องมือลากเส้นคานใหม่บนแปลน คลิกปรับความยาว ความกว้างคาน (ค่าเริ่มต้น `20 ซม.`), **ความสูงไม้แบบ (`40`, `50`, `60`, `70 ซม.`)**, และ **ความหนาไม้แบบ (ค่าเริ่มต้น `5 ซม.`)**
4. **`formworkOptimizer` (Corner Offset & Panel Fitting Engine):**
   * **การคำนวณความหนาไม้แบบและการชนมุม (Thickness & Corner Logic):**
     * คานแต่ละตัวมีไม้แบบข้างคาน 2 ฝั่ง (`Left Side` และ `Right Side`) ซึ่งมีความหนาแผ่นเท่ากับ `formworkThicknessCm` (เช่น `5 ซม.`)
     * เมื่อปลายคานชนกับคานอีกตัว (L-Corner หรือ T-Junction):
       * **มุมใน (Inner Corner):** ระยะวางแบบจะชนขอบในของคานที่ตัดขวาง
       * **มุมนอก (Outer Corner):** สามารถเปิด/ปิดโหมด **"อมมุม (+ ความหนาไม้แบบ)"** เพื่อให้ความยาวไม้แบบฝั่งนอกยื่นออกไปปิดความหนาไม้แบบของคานอีกฝั่ง (`+ thicknessCm`) ได้อย่างแม่นยำ
   * **อัลกอริทึมจัดเรียงแผ่นไม้แบบ (Dynamic Programming Optimization):**
     * สำหรับความยาวรวมแต่ละฝั่งคาน $L$ (ซม.) และความสูงที่กำหนด $H \in \{40, 50, 60, 70\}$:
       1. ค้นหาผลรวมของแผ่นขนาด `{120, 100, 50}` ที่ไม่เกิน $L$ โดยให้ **เหลือเศษความยาวฟรี ($R = L - \sum \text{panel}$) น้อยที่สุดเป็นอันดับแรก**
       2. หากมีหลายชุดที่ได้เศษ $R$ เท่ากัน ให้เลือกชุดที่ใช้ **จำนวนแผ่นรวมน้อยที่สุด** (ให้ความสำคัญกับแผ่น `120 -> 100 -> 50` ตามลำดับ)
       3. หาก $R > 0$ ซม. ระบบจะสร้างแผ่น **"ความยาวฟรี (Free Length)"** ขนาด $R \times H$ ซม. ต่อท้ายแถวอัตโนมัติ
5. **`summaryAndExport` (Interactive Summary Table & PDF/CSV Exporter):**
   * คำนวณยอดรวมแบบ Real-time ทุกครั้งที่มีการเพิ่ม/ลบ/แก้ไขคานหรือแผ่นไม้แบบ
   * ตาราง Matrix สรุปจำนวนแผ่นเช่าแยกตาม **ความยาว (`120`, `100`, `50 ซม.`) × ความสูง (`40`, `50`, `60`, `70 ซม.`)** พร้อมผลรวมจำนวนแผ่นและพื้นที่ (ตร.ม.)
   * ตารางสรุปรายการ **ระยะความยาวฟรี (ไม้ตัดเสริม)** แยกตามความสูง (`40`, `50`, `60`, `70 ซม.`) และความยาวแต่ละชิ้น
   * ส่งออกแปลนวางไม้แบบเป็นไฟล์ **PDF / PNG** และส่งออกตารางสรุปเป็นไฟล์ **CSV (เปิดใน Excel ได้ทันที)**

## 4. โครงสร้างข้อมูลหลัก (Core Data Models)

```typescript
export type FormworkHeight = 40 | 50 | 60 | 70; // ซม.
export type StandardPanelLength = 50 | 100 | 120; // ซม.

export interface Point {
  x: number; // พิกัดบนแปลน (PDF/Canvas space)
  y: number;
}

export type CornerAdjustmentMode = 'none' | 'extend_outer' | 'trim_inner';

export interface BeamSideConfig {
  side: 'left' | 'right';
  heightCm: FormworkHeight; // สามารถตั้งความสูงแยกฝั่งได้ หรือผูกตามความสูงคาน
  startExtensionCm: number; // ระยะยื่นอมมุม/หักมุมที่จุดเริ่มต้น (ซม.) - คำนวณอัตโนมัติจากความหนาแบบหรือปรับเองได้
  endExtensionCm: number;   // ระยะยื่นอมมุม/หักมุมที่จุดสิ้นสุด (ซม.)
  customPanels?: PlacedPanel[]; // กรณีผู้ใช้กด Edit ปรับขนาด/เรียงแผ่นเอง
}

export interface BeamElement {
  id: string;
  name: string;           // เช่น "B1", "B2"
  start: Point;           // จุดเริ่มต้นกึ่งกลางคาน
  end: Point;             // จุดสิ้นสุดกึ่งกลางคาน
  widthCm: number;        // ความกว้างหน้าคาน เช่น 20 ซม.
  defaultHeightCm: FormworkHeight; // ความสูงไม้แบบ: 40 | 50 | 60 | 70 ซม.
  thicknessCm: 5;         // ความหนาไม้แบบคงที่ 5 ซม. ทุกกรณี
  leftSide: BeamSideConfig;
  rightSide: BeamSideConfig;
}

export interface PlacedPanel {
  id: string;
  beamId: string;
  side: 'left' | 'right';
  type: 'standard' | 'free';
  lengthCm: number;       // 120, 100, 50 หรือความยาวฟรี (เช่น 35)
  heightCm: FormworkHeight; // 40, 50, 60, 70
  thicknessCm: 5;         // คงที่ 5 ซม. ทุกกรณี
  offsetStartCm: number;  // ระยะเริ่มจากต้นคาน
}
```

## 5. การออกแบบส่วนติดต่อผู้ใช้ (Minimal White UI & Interactive Workflow)

1. **แถบเครื่องมือด้านบน (Top Minimal Toolbar):**
   * `นำเข้า PDF แปลนคาน` (พร้อมปุ่มโหลดแปลนตัวอย่างทดสอบได้ทันที)
   * `ตั้งค่าสเกล`: ปุ่ม `Auto Scale` และ `Manual Scale (คลิก 2 จุด)` พร้อมแสดงค่าสเกลปัจจุบัน
   * `ตั้งค่าเริ่มต้น`: ความสูงไม้แบบเริ่มต้น (`40 / 50 / 60 / 70 ซม.`), ความกว้างคาน (`20 ซม.`), ความหนาไม้แบบ (`5 ซม.`)
   * `เครื่องมือทำงาน`: `เลือก/แก้ไข (Select)`, `วาดคาน (Draw Beam)`, `Auto-Detect คาน & วางไม้แบบอัตโนมัติ`, `คำนวณมุมชนอัตโนมัติ (Auto Corner Thickness)`
   * `ส่งออก (Export)`: `Export แปลน PDF/PNG` และ `Export ตาราง CSV`
2. **พื้นที่ทำงานตรงกลาง (Interactive CAD Canvas):**
   * แสดงแปลน PDF พื้นหลัง + เส้นคาน + แผ่นไม้แบบขนาบ 2 ฝั่งตามสเกลจริงและความหนาจริง
   * แสดงสีแยกตามความยาว (`เขียว 120`, `น้ำเงิน 100`, `ส้ม 50`, `แดงเส้นประ ระยะฟรี`) พร้อมตัวเลขกำกับ `ยาว×สูง`
   * ซูมด้วยลูกกลิ้งเมาส์ (Zoom), เลื่อนแปลน (Pan), คลิกเลือกคานหรือแผ่นไม้แบบเพื่อแก้ไขในแผง Inspector
3. **แผงด้านขวา (Right Sidebar - Inspector & Rental Summary Matrix):**
   * **แท็บสรุปยอดเช่าไม้แบบ (Summary Matrix):**
     * ตาราง Matrix แสดงจำนวนแผ่น (ชิ้น) แยกตามแถว **ความยาว (`120`, `100`, `50 ซม.`)** และคอลัมน์ **ความสูง (`40`, `50`, `60`, `70 ซม.`)**
     * ส่วนสรุป **ไอเท็มความยาวฟรี (ไม้ตัดเสริม)** แยกตามความสูง (`40`, `50`, `60`, `70 ซม.`) พร้อมบอกขนาดแต่ละชิ้นและจำนวนรวม
   * **แท็บแก้ไขคาน/แผ่นไม้แบบ (Edit Inspector - แสดงเมื่อคลิกเลือกคาน):**
     * แก้ไขชื่อคาน, ความกว้างคาน, ความสูงไม้แบบ (`40`, `50`, `60`, `70 ซม.`), ความหนาไม้แบบ
     * ปรับระยะอมมุม (`+ ความหนาไม้แบบ`) แยกฝั่งซ้าย/ขวา
     * แก้ไขรายการแผ่นไม้แบบในแต่ละฝั่งได้โดยตรง (เพิ่มแผ่น `120/100/50/Free`, ลบแผ่น, สลับลำดับแผ่น หรือกด `Reset เป็น Auto`)

## 6. การจัดการข้อผิดพลาดและการทดสอบ (Error Handling & Testing Strategy)

* **การจัดการข้อผิดพลาด (Error Handling):**
  * กรณีไฟล์ PDF ไม่มี Vector (เป็นภาพสแกนล้วน): แจ้งเตือนผู้ใช้ให้ทราบและเปิดโหมดตรวจจับเส้นภาพ (Canvas Line Helper) พร้อมสลับเข้าสู่เครื่องมือ `วาดคาน (Draw Beam)` และ `Manual Scale` โดยไม่เกิดการค้าง
  * กรณีความยาวคานสั้นกว่า 50 ซม.: ระบบจัดให้เป็นไอเท็ม `ความยาวฟรี (Free Length)` ทั้งชิ้นโดยอัตโนมัติ
  * มีปุ่ม **สร้างแปลนคานตัวอย่าง (Load Sample Beam Plan)** ในตัวแอป เพื่อให้ทดสอบระบบ Auto Scale, Auto-Detect และการวางไม้แบบได้ทันทีแม้ยังไม่ได้อัปโหลดไฟล์ PDF
* **การทดสอบ (Unit & UI Testing):**
  * **Unit Tests (Vitest):**
    * ทดสอบอัลกอริทึม `formworkOptimizer` (เช่น ความยาว 300 ซม. ต้องได้ `100×3` เศษ 0, ความยาว 270 ซม. ต้องได้ `120 + 100 + 50` เศษ 0, ความยาว 285 ซม. ต้องได้ `120 + 100 + 50` + `Free 15 ซม.`)
    * ทดสอบการคำนวณความหนาไม้แบบและการอมมุม L-Corner / T-Junction
    * ทดสอบการรวมยอด Summary Matrix ทั้ง 12 SKUs (`{120, 100, 50} × {40, 50, 60, 70}`) และรายการ `Free Length`
  * **Browser Verification:** ตรวจสอบการแสดงผล UI สไตล์ Minimal White, การอัปโหลด/จำลองแปลน PDF, การตั้งสเกล, การกด Auto วางไม้แบบ, การแก้ไขความสูง `40/50/60/70` และการ Export
